Why Knot

The bulk of Knot lives in a language server written in Rust that talks to editors through the Language Server Protocol. That design choice matters: Knot is not strictly tethered to VS Code. The VS Code extension is its first host, but the same Rust core can power other editors — and, in time, become a standalone IDE for Twine.

Most Twine tooling treats stories as text. Knot treats them as what they are: a directed graph of passages with variables flowing through it. Build the model the way the engine sees it, and the editor can answer real questions instead of approximating them.

Structural understanding

Knot parses your project into passages and the links between them. It answers "where is this variable set?" and "is this passage reachable?" with graph analysis — questions pure text matching gets wrong.

Version-aware SugarCube

The macro catalog is versioned end to end. Completions, hover docs, and diagnostics are filtered through the format-version in your StoryData — using a macro removed in SugarCube 2.37.0 gets an error with replacement guidance, not a silent runtime failure.

Variable tracker

See where every variable is set, read, and how it flows across passages. For SugarCube, tracking is JavaScript-aware via the oxc parser, so it understands <<set $x to 1>>, <<run $x++>>, and JS inside <<script>> blocks.

Passage diagnostics

A dedicated panel inspects any passage's links, variables, macros, and complexity. Real-time diagnostics cover broken links, unreachable passages, uninitialized variables, duplicates, and dead ends — 11 checks, each configurable.

CSS & HTML linting

Embedded stylesheets get parse errors, unknown-property lints against a 500+ property registry, and pseudo-class typo detection. Embedded HTML gets unclosed-element, duplicate-attribute, and directive checks — all inside passages.

Story Map

An interactive graph visualization of your project. Nodes are passages, edges are links. Click any node to jump to that passage in the editor. It updates in real time as you edit.

Incremental analysis

Only affected passages are re-parsed after each keystroke, so large projects stay responsive even as your story grows into hundreds of passages.

Build & play, no setup

One-click build and play via Tweego. Knot downloads and manages Tweego and story formats for you — no manual compiler setup, no PATH fiddling.

Get started in 60 seconds

  1. Install Knot from the VS Code Marketplace (search "Knot").
  2. Open a folder containing .tw or .twee files.
  3. Click Build in the status bar — Knot downloads Tweego and the right story format on first run.
  4. Click Play to open the compiled story in your browser.
